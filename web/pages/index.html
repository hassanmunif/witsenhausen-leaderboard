Witsenhausen’s counterexample

A verified leaderboard for a control problem that has been open since 1968

Two controllers act in turn on a Gaussian state \(x_0\). The first sees \(x_0\) exactly but pays for every push. The second acts for free but sees the result only through noise. The dynamics are linear, the cost is quadratic and the noise is Gaussian, yet Witsenhausen showed in 1968 that the best controllers are not linear. The optimal pair is still unknown.

This site tracks the best controllers found so far and the best proven lower bounds. Every cost is recomputed from a controller file by a reference evaluator (Section 3).
