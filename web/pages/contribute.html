6Contribute

A submission is one JSON file describing \(f\) as a piecewise-affine function. Nothing else is needed, because the evaluator computes \(g_f\) and the cost (Section 3). The steps below use GitHub; you can also send the file by email (About).

  1. Fork the repository and add submissions/<setting>/<your-name>.json. The README lists the four controller formats. The example below uses the odd one, which describes \(f\) for \(x \ge 0\) and extends it by \(f(-x) = -f(x)\).
  2. Run python scripts/score_all.py --check to see your verified cost.
  3. Open a pull request. The check re-scores every submission. It fails on malformed files, on controllers too large to evaluate quickly, on costs that cannot be computed reliably, and on a claimed cost that differs from the verified one by more than \(10^{-6}\).
  4. After the merge the site rebuilds and your entry appears on the leaderboard with its verified cost.
