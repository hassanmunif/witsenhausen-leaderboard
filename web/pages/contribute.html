Contribute

A submission is one JSON file describing \(f\) as a piecewise-affine function. Nothing else is needed, because the evaluator computes \(g_f\) and the cost. The steps below use GitHub; you can also send the file by email (About).

  1. Fork the repository and add submissions/<setting>/<your-name>.json. The controller formats are listed below; the example uses the odd one, which describes \(f\) for \(x \ge 0\) and extends it by \(f(-x) = -f(x)\). If an AI model helped, add "ai_assistance": one sentence naming the model and what it did. The leaderboard then tags your entry AI-assisted.
  2. Run python scripts/score_all.py --check to see your verified cost.
  3. Open a pull request. The check re-scores every submission. It fails on malformed files, on controllers too large to evaluate quickly, on costs that cannot be computed reliably, and on a claimed cost that differs from the verified one by more than \(10^{-6}\).
  4. After the merge the site rebuilds and your entry appears on the leaderboard with its verified cost.

Controller formats

Any controller can be submitted. Steps, sloped steps and other functions made of straight pieces are scored exactly; anything else is submitted as a table of points, and the table’s exact cost is what is verified. For a curved \(f\), place the points densely where it bends.

typeFieldsController \(f\)
lineargain\(f(x) = \mathrm{gain} \cdot x\)
piecewise_affinebreakpoints \((n-1)\), intercepts \((n)\), slopes \((n)\)\(f(x) = a_i + b_i x\) on \([t_i, t_{i+1})\); the first piece starts at \(-\infty\) and the last ends at \(+\infty\)
odd_piecewise_affinethe same fields, for \(x \ge 0\)pieces \([0, p_1), \dots, [p_m, \infty)\) for breakpoints \(0 < p_1 < \dots < p_m\), extended by \(f(-x) = -f(x)\)
pointsx, y; optional odd, extrapolationlinear interpolation through the table; outside it, "linear" continues the end segments and "constant" holds the end values. With "odd": true the table starts at \((0, 0)\) and \(f(-x) = -f(x)\).
